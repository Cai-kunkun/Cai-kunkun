## ⭐ Featured

### [Custom Splash](https://github.com/Cai-kunkun/custom-splash)

A mod that replaces or extends the Minecraft title screen splash text —
JSON config, colours, gradients, rainbows, placeholders and conditions.

[![Modrinth downloads](https://img.shields.io/modrinth/dt/arrbrants-custom-splash-texts?label=Modrinth&logo=modrinth&color=00AF5C)](https://modrinth.com/mod/arrbrants-custom-splash-texts)
[![Latest release](https://img.shields.io/github/v/release/Cai-kunkun/custom-splash?include_prereleases&label=release&logo=github)](https://github.com/Cai-kunkun/custom-splash/releases)
![Minecraft](https://img.shields.io/badge/Minecraft-1.14%20--%2026.3-blue?logo=minecraft)

- **86 build targets**: 48 Fabric · 20 Forge · 18 NeoForge, spanning Minecraft 1.14 through 26.3
- one standalone Gradle project per version, generated from a single shared source
- verified and released by CI on every push (9 build shards → GitHub pre-releases + Modrinth)

## 🛠 More of my stuff

- **[Controller](https://github.com/Cai-kunkun/Controller)** (Kotlin) — Android automation agent: screenshots go to a vision LLM, actions (tap / text / swipe / long-press) execute via root (KernelSU / Magisk)
- **[kew](https://github.com/Cai-kunkun/kew)** — music for the shell: a fast, immersive player that keeps your listening private
- **[ABK](https://github.com/Cai-kunkun/ABK)** (Kotlin) — AnyBase Kernel: build GKI kernels with your own ideas
- **[Arrium](https://github.com/Cai-kunkun/Arrium)** — a lightweight Chromium desktop browser built with Java + JCEF; multi-tab browsing, shipped as AppImage
- **[BetterUI](https://github.com/Cai-kunkun/BetterUI)** — a better UI for Minecraft
- **[osu-tools](https://github.com/Cai-kunkun/osu-tools)** — a tool for osu!
- **[bilibili_jump_and_report_helper](https://github.com/Cai-kunkun/bilibili_jump_and_report_helper)** — B 站中配视频跳转与举报助手（油猴脚本）
- **[auto_zako_program](https://github.com/Cai-kunkun/auto_zako_program)** — say zako, get taken to the zako video
- **[Axiom-app](https://github.com/Cai-kunkun/Axiom-app)** — an Android app exploring Material Design 3
